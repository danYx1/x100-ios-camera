# ZoomCam
Сборка .ipa через GitHub Actions (без Mac).
1. Создайте репозиторий на GitHub, загрузите все файлы (включая папку .github).
2. Actions → Build IPA → Run workflow (или просто push в main).
3. После зелёной сборки: Artifacts → ZoomCam-ipa → скачать ZoomCam.ipa (внутри zip).
4. Установка: Sideloadly или AltStore подпишут .ipa вашим Apple ID.
